# uniterm — v1.1 Audit Requirements

## Purpose

This file documents the **audit findings** as audit-stage "requirements" — issues to be addressed in future milestones. Each entry mirrors a finding from `.planning/audit/findings/{role}.md`.

**This is NOT typical GSD requirements** (no AC, no PR scope). It's an inventory of issues for downstream consumption.

## Format

```markdown
- [ ] **REQ-{CATEGORY}-{NNN}**: <title> [P{0-3}, <role>]
  - Location: file:line
  - Category: bug|perf|refactor|deps|config|os-compat|test|arch|docs
  - Evidence: <one-line>
  - Suggested fix: <one-line>
  - Test plan: <one-line>
  - Future milestone: v1.X
```
