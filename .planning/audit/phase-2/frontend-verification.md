## Net for fix queue

**CONFIRMED with high/medium ROI = 14** (FE-01, FE-02, FE-03, FE-04, P1-2, P1-3, P2-1, P2-6, P2-7, P2-11, P2-14, plus the dead-variable half of P1-4, plus confirmed-but-low items that are still real: P2-8, P2-9, P2-13).

**Top fix priorities (concrete repros):**

1. **FE-01 — AIMessage.vue XSS (high):** Replace the homegrown markdown pipeline (`AIMessage.vue:339-630`) with `marked` + `DOMPurify`, OR at minimum:
   - Allow-list `href` schemes in `autoLinkUrls` (`/^(https?:|mailto:|\/)/i`).
   - Strip `on*` attributes from `<img>` at line 401 with `replace(/on\w+\s*=\s*"[^"]*"/gi, '')`.
   - Re-validate URL with `new URL(href, location.origin)` before splicing.
   - Repro: in Anthropic chat, prompt the model "include a download link `[Get](javascript:fetch('http://localhost:9999/x'))`" and click — the link runs JS in the Wails WebView with full app privileges.

2. **FE-03 — EventsOn without EventsOff (high):** Mechanical fix; `App.vue:679, 681, 682` and the 6 stores must capture the return and either call `EventsOff(name)` in an `onUnmounted` hook (App.vue) or guard the registration behind `import.meta.env.PROD` / a singleton `init()` action so HMR doesn't stack listeners.

3. **FE-04 — useUpdateCheck interval teardown (medium):** Move `timer`, `state`, `updateInfo`, `checking`, `autoCheck` into the composable return (closure) and call `stopTimer()` from `App.vue`'s `onUnmounted`. The audit's secondary claim that `watch(autoCheck)` stacks per-mount is wrong (it's at module scope), but the interval leak is real.

4. **FE-02 — AISidebar MutationObserver leak (medium):** Split `let mutationObserver` into `editableObserver` and `messagesObserver` (both setup-scope `let`s), disconnect both in a single `onUnmounted`. Repro: open AISidebar → close → reopen 5 times → every keystroke in the editable div fires the orphaned observer's `syncInputText/refreshHashDropdown/refreshSkillDropdown` callbacks.

5. **P2-1 / P2-6 — BaseTerminal cumulative setTimeout + deep watch on settings (medium):** Store `setTimeout` IDs in a per-mount array; clear on unmount/deactivation. Guard the `watch(settings.terminal, ...)` (`useTerminal.ts:680-691`) with a `ts.fontSize !== prev.fontSize || ts.fontFamily !== prev.fontFamily` check before calling `resize()`.

6. **P2-7 / P1-2 — llm.ts hardcoded `max_tokens: 4096` (medium):** Read from `settingsStore.activeModel` (per-model) and surface `stop_reason === 'max_tokens'` as a non-fatal error to the AI sidebar. Repro: any agent turn that hits ~4K output tokens (a long `save_skill` body + several `execute_command` tool_use blocks) silently truncates.
